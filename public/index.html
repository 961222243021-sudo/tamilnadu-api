How to use Tamilnadu API

  1. Choose an election year. The archive contains 14 Assembly elections from 1967 to 2026.
  2. Find your constituency. Search its English name, supported Tamil name, or number, then choose it to see votes, the winner, and the winning margin.
  3. Use or save the data. Open the selected result as JSON, download that seat’s CSV, or download the whole election.

New to APIs? Start the complete guide →

For apps, send a GET request to an endpoint below. No signup or API key is required. This contains candidates’ vote totals; individual voters’ choices are secret and are not included.

Getting all rows: Lists return 50 rows by default. Check pagination.pages and request each page, or use CSV to download the full year. Even limit=500 does not return every losing candidate in one request.

List responses support page=1&limit=50 (maximum 500). Result lists also support q, party, status, and constituency_id.

const API_BASE = 'https://tamilnadu-api.vercel.app/api/v1';
const response = await fetch(
  `${API_BASE}/elections/2026/constituencies/1/results`
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { data, meta } = await response.json();
console.log(data.winner, data.winning_margin);
console.log(meta.official_row_verification);

Read the response: data contains the results; meta explains verification; pagination describes list pages. won means elected in that election, lost means a losing candidate, and nota is a separate voting option. A null percentage means the source totals need review.

Know what you’re comparing

These are general-election cycle results, not current officeholders or a full by-election history. Constituency numbers before 2011 must not be equated with modern boundaries. Party labels follow the source for each year. Candidate search returns records and does not establish that similarly named people are the same person.

Some source totals conflict. Those records retain their votes but omit computed percentages. District filters use the 2021 and 2026 source labels; 19 seats have no district label in the 2026 source. Tamil search currently covers five Tirunelveli constituencies from 2011 onward. Local-body and parliamentary elections are planned additions.
